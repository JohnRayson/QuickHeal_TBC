If you are using QuickHeal from CurseForge, https://www.curseforge.com/wow/addons/quick-heal and it was last updated Feb 13 2025 then this version will fix it.

All you need is the file QuickHeal.lua to replace the existing one

Click the file and then "download raw file" (top right)

Find the addon directory for classic TBC..

[wow]\_anniversary_\Interface\AddOns\QuickHeal

Then rename the file in there to QuickHeal.lua -> QuickHeal.lua.old

Copy the downloaded version into that folder.

This is a hack fix in that it is returning hard coded values for game versions, so it will only work for classic TBC

OR

You could just download the whole thing and put it in this folder

[wow]\_anniversary_\Interface\AddOns\QuickHeal
